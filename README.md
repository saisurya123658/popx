# PopX Authentication App

A modern MERN stack authentication application inspired by the PopX mobile UI experience.  
Built with React, Vite, Node.js, Express, MongoDB, and JWT authentication.

---

## 🚀 Live Demo

[https://popx-tawny.vercel.app](https://saisurya123658-popx.vercel.app/)

- 🔐 JWT Authentication

## ⚙️ Installation & Setup

### Clone Repository

```bash
git clone https://github.com/saisurya123658/popx.git
```

### Navigate to Project

```bash
cd popx
```

---

## 📦 Frontend Setup

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

---

## 🗄️ Backend Setup

Navigate to backend folder:

```bash
cd backend
```

Install backend dependencies:

```bash
npm install
```

Create `.env` file:

```env
PORT=5000
MONGODB_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
NODE_ENV=development
```

Start backend server:

```bash
npm start
```

---

## 🌐 Environment Variables

| Variable | Description |
|----------|-------------|
| PORT | Backend server port |
| MONGODB_URI | MongoDB connection string |
| JWT_SECRET | Secret key for JWT |
